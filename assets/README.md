# Radha Typing Tutor — Assets

All non-code resources referenced by the UI. Kept at the workspace root (not
inside `crates/radha-app`) because later phases share them with content tooling.
Everything here is local and embedded or shipped with the app — no CDN, no
runtime download (RULES.MD Rule 28).

## Layout

```
assets/
├── fonts/     Font binaries + licence files, embedded at compile time via ui/theme/fonts.slint
├── icons/     SVG icons, referenced directly from .slint files via @image-url
└── sounds/    Synthesised UI sound samples (WAV), generated by an example binary
```

`crates/radha-app/tests/asset_policy.rs` checks this folder on every
`cargo test --workspace`: fonts + licences present (no Kruti Dev / Mangal
files), the Lucide icons present and themeable, no black/blue colours in SVGs,
and the sounds valid and under budget.

## Fonts

Embedded at compile time by the `import "…/assets/fonts/<file>.ttf";` lines in
`crates/radha-app/ui/theme/fonts.slint` (which `ui/main.slint` imports). No CDN,
no runtime registration. `Typography` names each family by its single exact
name (`"Inter"`, `"JetBrains Mono"`, `"Noto Sans Devanagari"`) — Slint does not
resolve CSS-style comma fallback lists. Only the weights in use are shipped
(binary budget < 20 MB). Hinted static TTFs are used because Windows renders
hinted outlines more crisply at UI sizes.

### Not bundled

- **Kruti Dev — not bundled, licence check pending** (PRD.md Section 12.5).
  `Typography.family-krutidev` keeps the name and the import in `fonts.slint`
  stays commented out until redistribution rights are confirmed. There is no
  fallback: without the font, Kruti Dev text renders as Latin characters.
- **Mangal** — a Windows system font. Exam profiles that need it read it from
  the OS; it is never redistributed with the app.

## Icons

SVG, referenced from `.slint` via a relative `@image-url(...)`. Slint resolves and
embeds them at compile time, so a missing or malformed icon is a build error
rather than a blank space at runtime.

### Lucide (v0.344.0, ISC)

28 icons from [Lucide](https://lucide.dev) at git tag `0.344.0` — the version
the `design-reference/*.html` mock-ups load — copied unmodified from
`https://raw.githubusercontent.com/lucide-icons/lucide/0.344.0/icons/<name>.svg`.
Licence: ISC (includes the Feather MIT notice), see `icons/LICENSE-lucide.txt`.

`globe`, `message-circle`, `phone`, `lightbulb`, `share-2`, `shield-check`,
`search`, `bar-chart-2`, `user`, `settings`, `play`, `arrow-right`,
`check-circle`, `zap`, `hash`, `keyboard`, `award`, `lock`, `rotate-ccw`,
`pause`, `skip-back`, `skip-forward`, `printer`, `maximize-2`,
`sliders-horizontal`, `x`, `copy`, `volume-2` (`.svg` each).

Upstream renames on Lucide `main` (we keep the 0.344.0 names, matching the
reference HTML): `bar-chart-2` → `chart-no-axes-column`,
`check-circle` → `circle-check-big`.

All are 24×24 (`viewBox="0 0 24 24"`), `fill="none"`, `stroke="currentColor"`.
**Always set `colorize:`** on the `Image` (e.g. `colorize: Theme.text-tertiary;`)
— Slint does not resolve `currentColor` to a theme colour, so without
`colorize` the icon renders black.

### Custom icons

`analytics.svg`, `brand-mark.svg`, `facebook.svg`, `instagram.svg`,
`profile.svg`, `settings-solid.svg`, `theme-dark.svg`, `theme-light.svg`,
`youtube.svg` are project-authored. `settings-solid.svg` is the original solid
gear used by the Home header (renamed in P01 so Lucide could take
`settings.svg`); the previous custom `search.svg` was replaced by Lucide's.

Authoring rules for custom icons:

- Square viewBox (`0 0 24 24`) so icons align on a shared baseline.
- `fill="currentColor"` where the icon should take its colour from the theme;
  a hard-coded fill cannot follow light/dark switching.
- No black (`#000`) and no blue fills — see `DESIGN.md` Section 2.

## Sounds

Generated by:

```
cargo run -p radha-app --example generate_sounds
```

(`crates/radha-app/examples/generate_sounds.rs`). Pure math synthesis — no
recordings, no randomness, no third-party material, so there are no licence
obligations and the output is deterministic. The `.wav` files are checked in.
Format: RIFF/WAVE, PCM 16-bit, mono, 22,050 Hz, peak 0.35 of full scale, 3 ms
linear attack/release on every tone. Budget: < 300 KB total (currently
38,150 bytes).

| File | Duration | Design | Bytes |
|---|---|---|---|
| `key.wav` | 30 ms | 1,800 Hz sine, exponential decay τ = 6 ms | 1,368 |
| `error.wav` | 120 ms | 220 Hz + 233 Hz sines (soft beat), decay τ = 50 ms | 5,336 |
| `success.wav` | 180 ms | 660 Hz for 80 ms, then 880 Hz for 100 ms | 7,982 |
| `complete.wav` | 450 ms | 523.25 / 659.25 / 783.99 Hz (C–E–G), 150 ms each | 19,892 |
| `timer.wav` | 80 ms | 1,000 Hz sine, decay τ = 20 ms | 3,572 |

Sound design only — playback arrives in P06.
